01 — Method

Four phases, in order. Never skip to code.

The highest-leverage step isn't implementation — it's writing a spec so precise that implementation becomes transcription.

01

Commit to a direction

One reference feeling in 3–6 concrete words. One signature move — exactly one. A real design system with real values. "Modern and clean" is not a direction; it's the absence of one.

Write the build spec

Every element gets an exact size, hex, weight, tracking and easing before a single line is written.

Build

React · Tailwind · TypeScript · Framer Motion — the corpus-dominant stack, with recipes for each effect.

Audit against the quality bar

18 instant-tells that mark a page as AI-generated — purple gradients, centered everything, three identical cards, transition: all — each with the specific fix. Run it before declaring done.

#ffffff · #000000 · #1a1a1a · #111111 · #0a0a0a. Premium is neutrals plus restraint — color is punctuation, not paint.

Type

clamp() × 647

Display type is never a fixed size. Tracking tightens to −0.04em as it grows; labels widen to 0.2em.

Motion

600–800ms reveals

Hovers 150–250ms, staggers 60–120ms, total sequence under 1.2s. Only transform and opacity animate.

03 — Non-negotiables

Eight rules that separate designed from generated.

01

Type carries the design

A hero headline is clamp(2.5rem, 8vw, 7rem) — not text-5xl. Tight tracking, tight leading, at scale.

02

Contrast over decoration

Near-black or off-white ground, one accent used once or twice per screen, large fields of empty space.

03

One accent, deployed sparingly

If everything is highlighted, nothing is. Two appearances per viewport is the entire budget.

04

Motion is choreography, not decoration

If a user notices the animation before the content, it's wrong. Guide attention; never compete for it.

05

Never center everything

Asymmetry, off-grid placement and deliberate overflow are what read as art-directed.

06

Real content, always

Plausible product copy, real names, real numbers. No "Lorem ipsum", no "Feature One".

07

Full-bleed first screen

100dvh, one dominant focal element, brand identity legible in under three seconds.

08

Respect the user

Reduced motion, real focus states, alt text, keyboard reach, AA contrast on actual text.
